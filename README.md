# ExteriorBallistics-calculator_py-ballisticcalc-gui
 A desktop exterior ballistics calculator powered by py-ballisticcalc, featuring a Tkinter GUI and interactive Matplotlib charts - built for precision shooting and ammunition comparison. (Chinese only for now.)基于py-ballisticcalc制作的桌面外弹道计算应用，拥有Tkinter风格   界面和Matplotlib学术风格交互图表，面向精确射击与弹药对比场景。
